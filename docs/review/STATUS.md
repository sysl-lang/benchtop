# Review findings — status

The 88 findings of the code review in this directory (`cores.md`, `runtime.md`, `peripherals.md`,
`ui-firmware.md`; `SUMMARY.md` ranks them), one row each. The review read the `pico2-riscv` branch,
since merged, so its line numbers have moved. A status is **open**, **fixed in `<sha>`**, **fixed by
slice N** (the machine slices of [machine.md](../machine.md)), **partly fixed** (what is left is
said), or **n.a.** with the reason. Each one marked fixed was checked against the code, not assumed.

| runtime#1 | no board object: the machine is module globals shared across threads | partly fixed by slices 1–4 (`ce0b959`, `3024687`, `679528a`, `d72cffd`, `a53b6ff`, `9d54348`): memory, devices, scheduler, workers and cores are owned; the cores' configuration, clock and bus cache are `Machine`'s (`bb79bea`); the SIO's FIFOs, spinlocks and boot-ROM launch state are `Machine.devices.sio` (`b8df5cc`); fixed in `ad59dec` and `f33df59`: the global `virt.machine` is gone. `machine()` makes a machine in a box its owner holds (a `Session`, `benchtop run`, each test), every entry point takes a `*Machine`, the threads that run it are handed it, and the devices work on their own state, reaching the machine only through what they are handed.
